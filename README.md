# Programación en Java · DAM

Ejercicios de Java del módulo de Programación del ciclo de Desarrollo de Aplicaciones Multiplataforma (DAM) en ILERNA Online. Los subo a medida que avanzo.

## En qué estoy

Estoy empezando con Java. Ahora mismo practico: matrices bidimensionales y bucles anidados.

## Qué hay aquí

- `cuadernillo`: ejercicios del cuadernillo del módulo (operadores, condicionales, bucles y arrays)
- `gimnasio`: ejercicios cortos de práctica (conversión de unidades, IVA, días del mes)
- `videotutorias`: ejercicios de las videotutorías (operadores, entrada por consola, bucles)

## Cómo ejecutarlo

1. Instala el JDK (25) e IntelliJ IDEA.
2. Clona el repositorio y ábrelo con IntelliJ IDEA.
3. Ejecuta la clase con el método `main` del ejercicio que quieras probar.
